# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**. You'll get a reply as soon as I can, and I'll keep you updated until it's fixed.

## What counts

Agent trace reads Claude Code session data on your machine and saves traces locally. Reports about leaked or unmasked credentials in saved traces or exports, or about the plugin reading or writing outside its own folder, are especially welcome.

## Supported versions

Only the latest version on `main` is supported.
